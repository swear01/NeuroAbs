Now we need to verify one ISA property ADD on the opensource design PiCORV32. This design based on the RISC-V. The target property formally verify whether the ADD instruction can be correctly decoded and the executed. The instruction signal in the design is "mem_rdata". The instruction has 32 bit and the ADD instruction follows the format {7'b0,5'bx,5'bx,3'b0,5'bx,7'b0110011}. Please note that the signal in the process of fetching instruction (such as the signal mem_rdata_q, mem_rdata_latched) cannot be abstracted.
